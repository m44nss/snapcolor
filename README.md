# SnapColor — Color Palette Generator

SnapColor is a small, responsive color palette generator built with vanilla HTML, CSS, and JavaScript.

## Features

- Generate random five-color palettes
- Lock favorite colors while regenerating the others
- Copy HEX color codes
- Export palette colors as CSS custom properties
- Keyboard shortcut: Space
- Responsive layout for desktop and mobile
- No frameworks or build tools required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Generate a palette and copy your favorite colors.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Keyboard shortcut

Press the Space key when you are not typing in an input field to generate a new palette.
